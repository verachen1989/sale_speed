2. 周期选择
页面提供三个周期选项：
- 当日/当月/当年
3. 指标定义
页面中将显示以下指标，支持查看具体的套数和金额：
- 协议指标：协议套数、协议金额。
- 合同指标：合同套数、合同金额。
- 回款指标：包括现金、贷款回款及合计回款。
4. 维度筛选
用户可以根据不同的维度进行数据筛选，具体包括：
- 按项目类型：展示不同类型的项目，如当年首开、续销、尾盘项目。
- 按拿地年份：根据项目的拿地时间进行筛选。
- 城市：根据城市进行数据筛选（城市按项目占比由大到小排序）。
5. 趋势对比
页面提供趋势图与数据的对比分析，包括：
- 趋势：展示不同时间周期内的流速变化。
- 同比：展示同比增长情况，帮助用户进行周期间的趋势对比。
- 经营兑现对比：支持与年度经营计划版、首开定价会版、全景会版、经营策划会版、交底会版
