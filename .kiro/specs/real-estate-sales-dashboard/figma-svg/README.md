# SVG Static Drafts

These SVG files are static artboards intended for import into Figma as editable base drafts.

Files:

- `region-dashboard-default.svg`
- `region-dashboard-filter-open.svg`
- `project-detail-contract.svg`
- `project-detail-visit.svg`

Recommended Figma usage:

1. Import SVG into a dedicated page.
2. Lock the imported artboard as a visual base.
3. Rebuild key modules as Figma components on top.
4. Replace static labels and metrics with design-system text styles.
