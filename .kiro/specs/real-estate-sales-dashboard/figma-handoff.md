# Figma 交付包

本文档用于把当前“区域页 + 项目页”整理成可直接在 Figma 中重建的交付说明。

适用对象：

- 产品
- 设计
- 前端

覆盖范围：

- 集团/区域看板页
- 项目详情页
- 公共组件与状态

## 1. 交付建议

建议在 Figma 中建立以下页面：

1. `00 Cover`
2. `01 Foundations`
3. `02 Components`
4. `03 Region Dashboard`
5. `04 Project Detail`
6. `05 States`
7. `06 Notes`

5. 趋势图
6. 项目明细表

### 3.2 项目页结构

1. 顶部导航

5. 明细表

## 4. 区域页重建说明

### 4.1 顶部导航

元素：

- 返回按钮占位
- 页面标题：`绿城中国`
- 日期按钮
- 更多按钮

### 4.2 顶部筛选栏

筛选项顺序：

1. 周期：`当日 / 当月 / 当年`
2. 业态：`住宅 / 商办 / 车储`
3. 口径：`协议 / 合同`

设计要求：

- 筛选项使用轻量下拉样式
- 文字优先，边框弱化
- 切换后整页联动

### 4.3 概览卡

默认展示两张核心指标：

- 套数
- 金额

辅助信息：

- 环比

展开筛选态时右上角显示：

- `清空筛选`

收起态显示：

- `项目类型筛选`

### 4.4 分类筛选面板

分类按钮：

- 按销售状态
- 按拿地年份
- 按重点城市

子项卡片：

- 横向排列
- 支持首尾选中
- 中心吸附选中

卡片内信息：

- 标签名
- 套数
- 金额

### 4.5 趋势图

需要出 3 个周期版本：

- `近7日流速趋势`
- `近6周流速趋势`
- `近6个月流速趋势`

控制项：

- 套数/金额切换
- 当年版本对比

图例：

- 当日/当月：实际
- 当年：目标 + 实际

### 4.6 项目明细表

区域页明细表结构：

1. 标题
2. 字段筛选
3. 搜索入口
4. 合计行
5. 项目行列表

默认字段：

- 套数
- 金额
- 回款现金
- 回款按揭
- 回款合计

## 5. 项目页重建说明

### 5.1 顶部筛选栏

筛选项顺序：

1. 周期
2. 分期
3. 业态-二级分类
4. 业务分类：`协议 / 合同 / 来访`
5. 重置按钮

### 5.2 子项卡片区

默认模式：

- 第一张固定为 `全部已售`
- 后续为户型/子项卡片

卡片信息：

- 标签名
- 套数
- 剩余库存
- 金额

选中态：

- 绿色描边

交互态：

- 点击选中
- 横向滑动自动选中

### 5.3 协议/合同趋势图

标题规则：

- `近7日流速趋势`
- `近6周流速趋势`
- `近6个月流速趋势`

若下钻到子项：

- 标题追加子项名

控制项：

- 套数/金额切换
- 当年版本对比

图例：

- 当年：目标 + 实际
- 非当年：实际

### 5.4 来访趋势图

来访页在 Figma 中单独出一套，不与协议/合同共用图表头。

标题规则：

- `近7日来访组数`
- `近6周来访组数`
- `近6个月来访组数`

固定特征：

- 不显示套数/金额切换
- 不显示会议版本对比
- 不显示目标柱
- 不显示底部 3 个摘要指标
- 图例文案为 `来访组数`
- 单位为 `组`

### 5.5 项目页明细表

协议/合同场景下展示。

结构：

1. 标题
2. 横向日期列
3. 固定首列 `指标`
4. 首列表头下单位说明

字段：

- 协议/合同套数
- 协议/合同金额
- 回款合计
- 回款现金
- 回款按揭

来访场景：

- 不展示明细表

## 8. 建议标注

建议在 Figma 中明确标注以下规则：

1. 顶部筛选变化会联动图表与明细
2. 分类筛选切换会清空旧子项
3. 项目页切换来访后进入全盘模式
4. 来访不展示明细表
5. 子项卡支持滚动吸附选中
